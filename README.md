# Blind-Auction-Project
This is an auction program that collects users' names and bid amounts, then determines the winner based on the user with the highest bid.
The user will be asked to type their name, then type how much they'd like to bid. After the bid has been entered, the user will be asked whether there are any other bidders. Once all bidders have entered their bids and there are no other bidders, the program will name the user with the highest bid as the winner of the auction.
